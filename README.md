# WorkBuddy 字体插件

> 给 WorkBuddy 换界面字体。**只改字体，不动配色、不动字号、不动行距。**
> 网页上选字体，点一下就生效，不用重启。

[English](README.en.md) · [MIT License](LICENSE)

---

## 一、这是什么

一个给 **WorkBuddy 桌面端（Windows）** 换字体的工具。

- 在网页上从下拉框挑字体，**实时预览**，点「应用设置」就生效
- 字体列表从**你自己电脑**里扫出来，不用手打字体名（不会填错）
- 字号和行距**完全交给 WorkBuddy 自己的设置**，插件不去抢
- **不修改** `app.asar`、不碰安装目录、不破坏应用签名
- 全程只在本机操作（`127.0.0.1`），**不联网、不收集任何信息**

---

## 二、快速开始

### 需要什么

- Windows 10 / 11
- **Node.js 18 或更高**（[下载](https://nodejs.org/)）—— 唯一依赖
- 已装 WorkBuddy 桌面端

### 三步走

**第 1 步：生成启动器**

双击 `setup-cdp.bat`，同目录会生成 `Start WorkBuddy.cmd`。

**第 2 步：用它启动 WorkBuddy**

先**完全关闭** WorkBuddy（所有窗口 + 右下角托盘图标），再双击 `Start WorkBuddy.cmd`。

> ⚠️ **这一步必须这么做**：插件要通过 Chrome 调试端口（CDP）注入样式，
> 而这个端口只有启动时带了 `--remote-debugging-port` 参数才会打开。
> 用普通方式启动的 WorkBuddy 没有这个端口，插件用不了。

**第 3 步：打开设置界面**

双击 `settings.bat`，浏览器会自动打开设置页。

从下拉框选一个字体（能实时看到效果），点「**应用设置**」，约 2 秒后界面生效。

## 三、放在哪儿都行

整个目录可以**随便搬、随便改名**，所有脚本都从自身位置推导路径，没有写死任何路径。

推荐放在固定位置，比如：
```
C:\Users\Public\WB-Typography\      （所有用户可用）
```

## 四、日常使用

| 想做什么 | 怎么做 |
|---------|--------|
| 换字体 | 双击 `settings.bat` → 选 → 应用 |
| 刚装了新字体，想让它出现在列表里 | 设置页点「重新扫描字体」 |
| 想知道是否真的生效 | 设置页点「检查是否生效」 |
| 彻底关闭插件 | 双击 `remove.bat` |

**什么时候需要重新应用？**

- **完全退出并重启 WorkBuddy 之后** —— 样式只存在于内存里，重启就没了。
  重新用 `Start WorkBuddy.cmd` 启动，再点一次应用。
- 平时只是切窗口、开会话、开关文档 —— **不用管**，插件会自动处理。

## 五、关于字号和行距

**默认不管，这是故意的。**

WorkBuddy 自带界面字号缩放。插件如果强行覆盖，会出现这种情况：你在软件里调了字号，
插件一应用又给你打回原值 —— 纯粹折腾人。

所以**想调字号行距，直接在 WorkBuddy 里调**就行。

设置页里有个「接管字号与行距」开关，默认关闭。打开后插件会固定字号，
但代价是 **WorkBuddy 自带的字号调节对正文失效**。一般不建议开。

## 六、它是怎么工作的

```
settings.bat  →  server.js  →  写配置文件  →  注入 CSS  →  界面生效
                  ↑                              ↑
             settings.html              运行中的 WorkBuddy
            （你在网页上操作）             （样式只在内存里）
```

- **字体名从字体文件内部读取**。这里有个坑：CSS 里要写的字体名，
  和 Windows 注册表里显示的中文名常常不一样。
  比如注册表显示「霞鹜文楷」，但 CSS 里要写 `LXGW WenKai`。
  填错了不报错，但**完全不生效**。所以本工具直接把扫到的字体列在下拉框里让你选。
- 样式用 `<style>` 标签注入，**不碰官方任何文件**。
- `watcher.js` 每 3 秒检查一次，新打开的页面/文档自动补上样式；
  改配置约 2 秒自动生效。

## 七、文件都是干什么的

| 文件 | 作用 |
|------|------|
| `settings.bat` | ★ 平时就用这个，打开网页设置界面 |
| `settings.html` | 网页界面（选字体 / 实时预览 / 应用） |
| `server.js` | 本地服务，给网页提供接口（`127.0.0.1:8787`） |
| `config.json` | 配置文件，网页改或手改都行 |
| `scan-fonts.js` | 扫描本机字体 |
| `build-css.js` | CSS 生成器（读配置 → 生成样式） |
| `inject.js` | 一次性注入 |
| `watcher.js` | 常驻监视（处理新开页面 + 配置热更新） |
| `verify.js` | 命令行验证是否生效 |
| `setup-cdp.bat` | 首次配置：生成启动器 |
| `apply.bat` | 命令行方式应用（网页之外的备选） |
| `remove.bat` | 卸载（官方外观完全不受影响） |

## 八、常见问题

**Q：设置页打不开，提示连不上服务？**
要双击 `settings.bat` 启动，**不能直接双击 `settings.html`**。
直接开 HTML 文件会因为浏览器的同源策略连不上本地接口。

**Q：我的 WorkBuddy 装在别的位置？**
```
setup-cdp.bat "C:\你的路径\WorkBuddy.exe"
```

**Q：改了没反应？**
按顺序排查：
1. WorkBuddy 是用 `Start WorkBuddy.cmd` 启动的吗？
2. 点一下设置页的「检查是否生效」，看显示的实际样式
3. 看命令行窗口有没有报错

**Q：会不会跟官方换肤功能打架？**
不会。插件用独立的样式标记，也不设置官方那些属性，
跟官方外观功能和其他皮肤插件互不干扰，可以同时用。

**Q：安不安全？**
- 只跟本机 `127.0.0.1` 上的 WorkBuddy 通信，**不联网**
- 不读你的任何文件、密码、Token
- **不修改** `app.asar`、安装目录、数字签名
- 所有脚本都是明文源码，可以自己看

**Q：为什么字体改了，界面没变？**
最可能是 WorkBuddy 不是用启动器开的（端口没开）。
另外注意：设置页下拉框里选的是**字体内部名**，不是你注册表里看到的中文名。

## 九、已知限制

1. 必须用 `Start WorkBuddy.cmd` 启动 WorkBuddy（原因见上面第 2 步）
2. 完全重启 WorkBuddy 后样式失效，重新应用一次即可 —— 这是技术方式的固有限制
3. 调试端口只绑定本机。插件运行期间，别运行来路不明的本机程序
4. WorkBuddy 更新后界面结构可能变化，个别区域可能覆盖不到
5. 只支持 Windows
